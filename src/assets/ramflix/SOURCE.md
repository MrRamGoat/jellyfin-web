# RamFLIX client source

RamFLIX is a modified Jellyfin Web client based on Jellyfin Web v12.2.
Corresponding source and build instructions:
https://github.com/MrRamGoat/jellyfin-web/tree/ramflix-v12.2.0-20261009

Jellyfin and RamFLIX client code: GNU GPL version 2 or later.
See JELLYFIN-LICENSE.txt in this directory and LICENSE in the source repository.
Outfit font: SIL Open Font License 1.1; see OFL.txt.

Native Jellyfin authentication, media playback, Live TV, permissions, and
SyncPlay remain provided by Jellyfin. Feature services are optional server
components; their source is maintained separately from the web client.
